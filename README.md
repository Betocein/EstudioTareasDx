# Estudio y Tareas: teléfono + reloj (Wear OS)
- Teléfono (app): asignas materias, tareas, fecha y minutos de estudio. Pestaña Progreso con el resultado.
- Reloj (wear): eliges una tarea, corre el cronómetro y marcas "Terminé de estudiar" o "Tarea terminada".

## Pasos
1. En Supabase > SQL Editor ejecuta `cambio-supabase.sql` (una sola vez).
2. Crea el archivo `local.properties` en esta carpeta con tu SUPABASE_URL y SUPABASE_KEY (ver local.properties.example).
3. Abre ESTA carpeta con Android Studio (File > Open) y espera el Sync.
4. Corre `app` en el teléfono y `wear` en el reloj.
